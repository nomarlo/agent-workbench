agent-workbench

Tools that make agent-driven development verifiable

Each tool is a self-contained Claude Code plugin, generalised out of a real codebase, with a runnable example and a live demo regenerated from the current code on every push.

arch-lens

A generated architecture view of a branch, set against the plan it was built from: layer violations, unplanned and missing files, flows.

 
/plugin marketplace add nomarlo/agent-workbench
/plugin install arch-lens@agent-workbench
