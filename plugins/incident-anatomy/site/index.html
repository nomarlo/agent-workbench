agent-workbench · incident-anatomy

An incident, explained so that it can be checked

An interactive page for one incident: a step-by-step simulation of the mechanism over the real code lines, what stays retained, the measured evidence, and the fixes as real patches you can toggle to see which path disappears.

Open the live example →

What is checked, and by whom

  • Code lines are read from git at a pinned commit, with their real numbers. A step can only highlight lines inside its excerpt.
  • Fixes are git diff patches that must apply cleanly to that commit.
  • Charts and data tables are drawn from the CSV files named in their captions.
  • The prose is checked last, by a subagent that has to find the evidence for every number and causal claim.

The example is a synthetic leak in a small export worker. Its evidence comes from running the worker 150 times, with and without each fix, under tracemalloc. The tests fail if the page's claims stop matching that measurement.
